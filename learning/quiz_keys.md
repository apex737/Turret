# 확정 문항 채점 기준 — Part 3 (Q29~Q37)

> **확정 문항을 풀기 전에는 열지 않는다.** 출제 시(2026-10-22) 정했고, 답을 본 뒤에 바꾸지 않는다 (GUIDE.md 5절). 채점이 끝나면 각 문항 밑 `판정:`으로 옮긴다.

- Q29 [S1] 15~20 kHz 성분이 30 − f로 둔갑 → 10~15 kHz에 떨어진다 (분석 대역 안). 그래서 ADC 앞 아날로그 필터나 더 높은 fs가 필요.
- Q30 [F2] (a) 36° = 0.1바퀴 → τ = 0.1 / 1000 Hz = 100 µs (MIC2가 늦음). (b) −108°. (c) 원점을 지나는 직선, 기울기 = −2πτ (위상 = −2πfτ).
- Q31 [R6] `drop++`는 읽기 → 더하기 → 쓰기. main이 읽은 뒤 쓰기 전에 ISR이 증가시키면 main이 옛 값 + 1로 덮어써 ISR의 증가가 사라진다. 대책: 임계 구역(인터럽트 끄기)/원자 연산, 또는 쓰는 쪽을 하나로(카운터를 따로 두고 합산).
- Q32 [R3] (a) HSI = 칩 안 RC 발진기(하드웨어), 공정·온도로 % 단위. HSE = 외부 수정(또는 ST-LINK의 수정 기반 클럭), ppm 단위. (b) 1800 s × 50e-6 = 90 ms. 30 fps 프레임 33 ms의 약 3프레임 → 장시간이면 주기적 시각 맞춤(공통 시각 기록) 필요.
- Q33 [M1] 같은 소리의 파생본이 학습·검증 fold에 갈라짐 = 누수 → 검증 점수가 낙관적 → 정한 문턱으로 운용하면 오탐이 예상보다 많다. 원음과 녹음본은 같은 묶음(group)으로.
- Q34 [I1] (a) 방향: 125000/12500 = 10.0 s ~ 10.5 s (131250). 분류: 9.5 s ~ 10.5 s. (b) 방향 창이 분류 창 안에 있어 겹침 → 짝지어도 된다 (지연 규칙 안이면).
- Q35 [I2] (a) "판단 불가" (오래된 판정·방향을 쓰지 않음). (b) 각 결과의 구간(샘플 번호)으로 나이를 계산해 유효기간 지난 것은 버리고, 가장 최근 구간이면서 현재 방향 창과 겹치는 것만 결합한다. 도착 순서·도착 시각으로 판단하지 않는다.
- Q36 [R4] (a) 48% + 1/20.48(약 5%) + 6/20.48(약 29%) ≈ 82%. 100%는 안 넘지만 70% 여유 목표를 넘는다. (b) 평균이 아니라 프레임별 최대 처리 시간(DWT)을 장시간(30분) 기록, 큐 깊이·qdrop·drop 0 확인.
- Q37 [R5] MCU: 리셋·멈춤 없이 수음·방향 계속 (drop·OVR 0, 송신 큐 유실은 GAP로 표시). PC: 빈 seq로 단절을 감지하고 그 구간을 무효로, 재연결 후 CRC·버전 맞는 패킷으로 재동기화하고 정상 창을 채운 뒤 복귀. 카메라 출력: 단절 동안 "판단 불가", 오래된 방향을 쓰지 않음, 복귀 후 정상.
