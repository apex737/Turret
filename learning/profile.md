## 1. 배경 (베이스라인 1)

- 전공/경력: (사용자 작성)
- 익숙한 언어/도구: C (STM32 HAL, CMSIS-DSP), Python (numpy, scipy, matplotlib, pyserial, scikit-learn, PyTorch), STM32CubeIDE
- 설명 선호: 시각화/표 위주 -> (필요한 경우) 수식 -> (요청한 경우) 코드
- 개념 정리 선호 형식 (2026-10-22): 긴 교재 대신 개념 하나를 네 칸으로 짧게
  1. **핵심 키워드** — 검색할 수 있는 개념 이름
  2. **간략한 설명** — 그 개념이 무엇인지 1~2줄 (문항의 정답 풀이가 아님)
  3. **프로젝트 맥락** — 이 프로젝트의 어느 단계·코드·결정에서 왜 필요했는지 1~2줄 (실제 숫자·파일·함수 이름)
  4. **쓰인 위치** — 단계 문서 링크
  - 공부 자료는 내가 고른다. 설명이 짧기만 하면 맥락이 없어 와닿지 않고, 길면 교재가 된다.
