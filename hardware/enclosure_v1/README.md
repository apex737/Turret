# 1·2·3층 최종 외장 시제품 — mm

이 묶음은 합의한 하우징, 층간 연결부, 보드 XY 위치 프레임 및 기존 배터리 조임대의 STL/STEP이다. 모터·카메라 지지대와 구동 전달계는 규격 미정으로 포함하지 않았다. 회전 토크와 실물 출력 조립은 아직 검증하지 않았다.

## 출력 수량

| STL | 수량 | 용도 |
|---|---:|---|
| `stl/1_1.stl` | 4 | 1층 동일 조각 |
| `stl/2_1.stl` | 2 | 2층 외벽 Ø10 구멍 2개 |
| `stl/2_2.stl` | 2 | 2층 외벽 Ø10 구멍 1개 |
| `stl/3_1.stl` | 2 | 3층 반구 조각 A |
| `stl/3_2.stl` | 2 | 3층 반구 조각 B |
| `stl/board_XY_locator.stl` | 1 | 보드 위치 프레임 |
| `stl/battery_01_adjustment_screw.stl` | 1 | 배터리 조임용 출력 나사 |
| `stl/battery_02_threaded_moving_slide.stl` | 1 | 이동 조임판 |
| `stl/battery_03_insert_slider_base.stl` | 1 | 수정한 배터리 베이스 |
| `stl/battery_04_opposite_corner.stl` | 1 | 반대편 고정 코너 |
| `stl/battery_05_shaft_retaining_clip.stl` | 1 | 나사 축 고정 클립 |

본체 12조각, 내부 부품 6개로 총 18개다. `fit-test/`의 홈·돌기 시험편 2개는 별도이며 먼저 출력해 끼움과 윤활 후 마찰을 확인하는 용도다. 시험편은 완전한 회전 성능 시험이 아니다.

STL은 단위 정보가 없으므로 **mm로 가져온다**. STL은 출력물별 XY 중심·Z바닥 0으로 정렬했다. 조립 좌표는 `step/`과 `reference/assembly.step`을 사용한다. 조립 STEP은 프린터용이 아니다.

## 확정 반영 치수

- 외경 Ø200, 1·2층 높이 각 100, 벽과 바닥 4. 반구의 원래 반경 100, 벽 4, 중앙 슬롯은 로컬 XZ 평면을 따라 Y방향 폭 15다. 15 슬롯으로 꼭대기가 제거되어 실제 최고점은 100보다 조금 낮다.
- 바닥의 X자 겹침면: 길이 80·폭 10, 반경 R10 ~ R90. 명목 2+2 턱에 상하 총 0.15, 끝·가장자리 0.2 여유를 적용했다. 실제 턱 두께는 각 1.925다.
- 1·2층 바닥 체결: 맞댐부마다 R15·R85에 Ø3.6, 층당 나사 축 8개. 3층은 R50에 하나씩 총 4개다. 한 축에서 두 조각에 뚫린 구멍을 같은 나사가 통과한다.
- 바닥 나사는 M3·평와셔·너트로 조인다. 1·2·3층의 체결 축 수 합계는 20이다. 양단 너트라면 이들 축에 너트 총 40개가 필요하다. 볼트 길이는 실제 겹침 두께와 너트·와셔에 맞춰 선택한다. 내부 부품 추가 체결 하드웨어는 별도다.
- 1층 배터리 베이스: 원래 Ø192.8에서 기능부를 유지하고 170×170 및 외곽 R95.65 안으로 잘랐다. 1층 바깥쪽 R85 체결 4곳을 연장해 함께 고정한다. 과거 3개 장착공은 이 조립에서는 사용하지 않는다.
- 2층 외벽 Ø10 총 6개는 60° 간격·높이 50. 2_1→2_2→2_1→2_2 순으로 조립한다. 한 곳씩 건너 3개를 쓰면 120°다.
- 2층 R50의 Ø5 네 구멍은 보드 프레임 핀용. 별도 전원선 Ø8 네 구멍은 R88이다. 중앙 Ø20도 유지했다.
- 보드: Orin 100×79 중심 (0,-25), STM32 80×50 중심 (0,55). 받침면 z10, 턱 높이 3·두께 2, 옆면 여유 각 0.3. 프레임은 핀으로 XY 위치만 잡고 위로 빠진다.

## 층간 조립

1. 1층 네 조각을 바닥 M3 체결부로 연결한다. 안쪽 나사 R15의 돌출은 바닥 상면에서 5 이내로 제한한다.
2. 수정한 배터리 베이스를 넣고 바깥 R85 네 체결 축으로 함께 고정한다. 나사 축·가동판·코너·클립은 유지된 조임대 구조로 조립한다. 출력 나사는 **커스텀 Ø10 P2이며 ISO M10이 아니다.**
3. 2층 2_1/2_2를 번갈아 조립하고 바닥의 8곳을 체결한다. 프레임 아래 체결 하드웨어 돌출은 바닥 상면에서 5 이내로 제한한다.
4. 1–2층은 돌기를 J홈에 정렬해 삽입하고, 위에서 보아 반시계 20° 돌린 뒤 0.8 내려 안착한다. 진동에 의한 들림/역회전을 막는 별도 잠금장치는 없다.
5. 2층 프레임 핀을 Ø5 네 구멍에 넣고 보드를 위에서 얹는다. 전선은 Ø8 전용 구멍으로 올린다.
6. 3층 3_1/3_2를 번갈아 조립해 바닥 네 곳을 체결한다. 2층 상단의 홈에 3층 돌기 링을 내려 얹는다. **2–3층은 J잠금이 아니라 원형 미끄럼 연결이다.**

## 2–3층 미끄럼 단면

- 2층 상단을 안쪽으로 넓혀 R92 ~ R100, 높이 z92 ~ 100 받침부를 만들었다.
- 홈: 내반경 94.6·외반경 97.4, 폭 2.8, 깊이 4.
- 3층 아래 돌기: 내반경 95·외반경 97, 두께 2, 아래로 길이 5.
- 조립 시 돌기 끝이 홈 바닥에 닿아 하중을 받고, 양옆 틈새는 각 0.4, 두 하우징 사이 높이 간격은 1이다. 1층 z0, 2층 바닥 z100, 3층 바닥 z201 기준이다.
- 위로 들어 올리면 빠지는 중력 안착 구조다. 임의로 휴대·뒤집을 때 고정되는 구조가 아니다.
- 홈은 4개 분할 경계를 통과하므로 단차와 돌기를 제거해야 한다. 윤활제는 재질 호환을 확인한 뒤 얇고 고르게 바른다. 윤활량만으로 낮은 회전 토크가 보장되지는 않는다.

## 확인 결과와 남은 사항

자동 검사 결과는 `reports/verification.json`, 출력 크기·수량은 `reports/print-list.csv`에 있다. BREP 유효성, 단일 솔리드, 조립 부품 간 간섭, J홈 이동 및 3층 회전의 샘플 위치, STL 밀폐성·방향·연결 성분·부피와 180 범위를 검사한다. 연속 운동 전체의 수치적 보증이나 강도 해석은 아니다.

출력 공차, 마모·기동 토크, 윤활제 호환성, 보드 밑면 부품과 실제 커넥터, 프린터 슬라이서·서포트는 실물 확인 전이다. 2층 하단 칼라와 3층 하단 돌기 때문에 바닥 아래 서포트가 필요할 수 있으며, 반구 안쪽도 슬라이서에서 검토한다. 여유 없는 180 경계까지 키우지 말고 실제 빌드 영역과 브림을 확인한다.

3층 Y축 카메라 틸트는 설계 목표만 기록된 상태다. 카메라·스테퍼의 규격, 암 길이·축 위치, 지지 베어링, 구동 벨트/기어와 슬립링 고정대는 STL에 포함하지 않았다. 이 자료만으로 완성된 구동 장치가 되지는 않는다.

## 재생성

원본 폴더 구조와 `runtime/cad-libs`, 배터리 조임대 STEP, 보드 프레임 STEP을 보존한 채 `etc`에서 실행한다.

```powershell
python source/final_build.py
```

`final/source/`는 빌더의 검토용 스냅샷이다. 단독 ZIP에서는 원본 CAD 입력과 CadQuery 런타임을 찾을 수 없으므로 재생성은 원본 `etc/source/`를 기준으로 한다.
