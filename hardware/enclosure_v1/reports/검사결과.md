# 오류 수정과 검사 결과

단위는 mm. 이 문서는 이번 최종 빌드에 적용한 변경과 한계를 구분한다.

## 발견해서 수정한 문제

| 문제 | 수정 |
|---|---|
| 기존 1층 모델은 벽/바닥 3이었으며 최신 4분할 결속과 달랐음 | 벽/바닥 4, 동일 조각 네 개, 4개 J홈과 8개 나사 축으로 재생성 |
| 배터리 베이스 Ø192.8이 새 내경 Ø192 및 프린터 180에 맞지 않음 | 기능부는 유지하고 외곽을 170×170·R95.65 안으로 다듬음. 바깥 R85 바닥 나사 네 곳에 맞는 장착공 추가 |
| 나선 나사의 CAD 기본 부피와 STL 부피 차이 약 0.56%로 자동 검사 중단 | 적응형 부피 적분으로 기본 CAD 계산 오차 확인. 고해상도 메시와 정밀 적분값 차이는 약 0.0034%. 최종 검사는 모든 부품에 정밀 적분을 적용 |
| 보드 턱의 두 팔이 모서리 선으로만 접촉해 STL 에지에 면 네 개가 만남 | 여덟 모서리에 2×2 연결 블록을 채워 연속된 L자 턱으로 수정. 수정 후 밀폐성 통과 |
| 바닥 겹침부가 명목상 완전 일치해 출력 시 끼임 가능 | 상하 총 0.15, 끝과 가장자리 0.2 여유 적용. 실물 출력 공차 자체는 시험 필요 |

## 통과한 자동 검사

- 주 출력 STL 11종, 시험편 STL 2종: 유효한 단일 솔리드에서 생성했으며 밀폐 메시·일관된 면 방향·연결 성분 한 개·양의 부피 확인.
- 모든 출력 부품은 X/Y/Z 각각 180 미만. 최대 평면 크기는 배터리 베이스 170×170.
- 각 층의 네 조각 간 여섯 쌍씩 체적 간섭 없음.
- 1–2층 J연결의 삽입·회전·안착 샘플 위치에서 체적 간섭 없음.
- 2–3층 0·15·30·45·60·90·135·180·270·360° 회전 샘플에서 체적 간섭 없음. 돌기 끝과 홈 바닥의 지지 접촉은 의도한 접촉이다.
- 배터리 조임대 부품 사이 및 1층 하우징과 체적 간섭 없음.
- 보드 프레임과 2층 하우징 사이 간섭 없음. 네 Ø8 전선 경로가 프레임·하우징에 막히지 않음.
- 상세 수치는 `verification.json`에 기록.

## 아직 검증하지 않은 사항

- 2–3층 미끄럼 구조의 기동 토크·스틱슬립·마모와 윤활제/필라멘트 호환성. 윤활제를 넣어도 저토크가 자동 보장되지는 않는다.
- 원형 홈의 네 분할 경계 단차. 출력 후 레일 표면 정리 및 조립 높이 맞춤 필요.
- 2–3층은 중력 안착이며 들어 올리면 빠진다. 들림 방지 장치 없음. 1–2층 J연결에도 별도 진동 방지 잠금장치는 없음.
- 부품 강도, 하중에 따른 처짐, 장시간 사용 및 완전한 연속 운동 해석.
- 슬라이서, 서포트 제거, 실제 프린터의 사용 가능 영역. 180 범위는 CAD/메시 외곽에 대한 검사다.
- 실제 PCB 뒷면 부품·커넥터 외곽, 케이블 굽힘, 슬립링 장착 및 카메라/모터 구동계.

이 자료는 외장과 합의된 내부 홀더의 시제품 출력 자료이며, 모터·카메라 지지대까지 완성된 장치의 제작도는 아니다.
