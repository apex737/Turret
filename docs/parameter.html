묶기 · 새 파라미터는 "이 값을 바꾸면 Top10 중 어느 것의 득실이 같이 바뀌나"로 하나에 붙인다. 두 곳에 걸리면 더 직접 영향을 주는 쪽 하나만 고른다. 어디에도 붙지 않으면 Top10을 다시 고를 신호다.

근거는 "왜 이 값인가"에 답하는 기록만 적는다. 목적·역할은 근거가 아니다. 제대로 된 근거가 없으면 비워 두고 검증할 것에 무엇이 빠졌는지 적는다. 실험 결과는 이 값(또는 대안)으로 실제로 돌려 본 기록만 적고, 실측·시뮬·계산을 앞에 밝힌다. Top10의 ½배·2배 득실은 parameter.json의 top10에서 직접 고친다.
