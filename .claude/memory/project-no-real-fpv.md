2026-10-14 사용자 결정: 실제 FPV 확보는 매우 어렵거나 막바지에나 가능하므로 **없다고 보고 진행**한다. 2026-10-26 대상이 소형 고정익 정찰기로 바뀐 뒤에도 같다 — 그 기체는 더더욱 구할 수 없다 ([[project-product-direction]]).

**Why:** 기체·조종 협조를 구할 수 없고 예산도 없다. 그래서 양성 데이터는 공개 원음을 스피커로 재생해 MAX4466 3ch로 녹음한 것, 또는 급이 비슷한 대용 음원(예: 소형 2행정 엔진)이 전부다. 원음 선정이 성패를 좌우한다(사용자 강조).

**How to apply:** 실비행 검증은 맨 뒤 조건부 단계로 둔다. 원음 선정 기준(무편집·무해설, 고샘플레이트·무손실, 지상 원거리 수음, 기체 종류 명시, 라이선스)을 엄격히 적용하고, 스피커 재생 체인이 원음 특징을 보존하는지 실측으로 확인한다. 스피커 착색을 분류기가 학습하지 않도록 비드론 음도 같은 스피커로 재생해 음성(negative)에 넣는다. 탐지 거리는 재생 녹음으로 직접 잴 수 없으니 "탐지 문턱 dB × 음원 음량" 계산으로 추정한다 (2026-10-27 제안, 미실행). 관련: [[reference-drone-audio-sources]], [[project-goal-drone-detection]]
