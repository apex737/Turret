2026-10-14 Step5(하드웨어 기준선) 초안에 대한 사용자 반응: "오버엔지니어링", "마이크로 매니징", "의미가 있는지 의문", "손가락 스냅을 또 레퍼런스로 삼는 게 맘에 안 든다", "빠르게 고조파 검출기와 드론 패턴 학습으로 넘어가자".

**Why:** (당시 맥락: 브랜치를 `FPV_Target`으로 바꾼 것 자체가 스냅 시절 설계를 버린다는 뜻. 2026-10-26 대상은 고정익 정찰기로 다시 바뀜 — 원칙은 그대로.) 150~2000 Hz 대역은 스냅 + c/2d 조건에서 나온 값일 뿐 지켜야 할 기준선이 아니다. BPF 기반이냐 고조파 중심이냐도 아직 미정. 하드웨어 신뢰성 점검(OVR, DWT 주기, 전기 동시성 등)은 다음 설계 결정을 바꾸지 않으므로 Step으로 세울 가치가 없었다.

**How to apply:**
- Step의 작업은 "이 결과가 다음 설계를 바꾸는가"로 거른다. 바꾸지 않는 점검은 빼거나 한 줄로 접는다.
- 스냅/클릭 경로를 회귀 기준·정답 시험에 쓰지 않는다. 기준선은 드론 소리 기준으로 새로 잡는다 ([[workflow-baseline-pivoting]]의 기준선도 드론 기준).
- 기존 대역·상수(150~2000 Hz, TDOA_WIN 5 ms 등)를 "맞춰야 할 값"으로 다루지 않는다.
- 체크박스를 잘게 쪼개지 않는다. 손/AI 분담 표시는 핵심부만.
