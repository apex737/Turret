확정된 설정(baseline)을 먼저 정의해 고정하고, 그것을 기준으로 여러 테스트를 하며 피버팅하는 방식을 선호한다.

**Why:** 사용자가 직접 말함(2026-10-11). 여러 값을 동시에 바꾸면 효과를 분리할 수 없기 때문.
**How to apply:** 튜닝/실험 제안 시 기준선 값부터 명시하고, 한 번에 한 변수만 바꾸는 테스트로 설계한다. 변경 결과는 기준선 대비로 보고한다.
