사용자의 목표 직무는 **제어·추정(Controls & Estimation) + 신호처리 임베디드 펌웨어 (학사 신입)**다 (2026-10-25). 상세는 `learning/profile.md` 3절.

- 집중 역량 3: 실시간 구현(주기·지터·부하를 숫자로), 이산시간 신호·시스템(앨리어싱·FIR/IIR·위상 지연·이산화), 모델링·상태추정(KF Q·R의 물리적 의미).
- 압도적으로 잘해야 할 1가지: 이론(예측)과 실측의 차이 원인을 좁혀 찾는 능력. 사례를 문서·AI 없이 다시 설명할 수 있어야 함.
- ML 모델 설계는 우선순위 낮음 (블랙박스).

**How to apply:** GUIDE v2.2 5절 "목표 직무 반영"대로 모든 트리거 문항을 면접관 질문 형태로(프로젝트 실제 숫자로), 역량을 돌아가며, 예측·고장 진단 유형 비중을 높게, 꼬리 질문 하나. T4에는 "예측 → 측정 → 차이 → 원인 2분 설명" 문항 필수. 프로젝트 방향을 제안할 때도 이 직무에 가까운 쪽(KF·실시간·DSP)을 우선 고려한다.
