## 질문과 답
**Q.** 마이크 3개를 같은 순간에, 일정한 간격으로, 끊김 없이 잴 수 있는가?

**A. 예.** ADC1 ~ 3 삼중 동시 변환(TIM2 50 kHz 트리거)과 DMA 핑퐁으로 `drop_cnt` 0, 각 채널 바이어스 약 2048·조용할 때 p2p 50 ~ 100을 확인했다. 실제 샘플링 속도와 채널 간 전기적 동시성은 재지 않았다.

## 최종 목표와의 연결
- G1: 방향은 세 채널의 도달 시간차(µs 단위)로 구하므로 동시 변환과 일정한 간격이 전제다.
- G4: 핑퐁 버퍼의 마감(반버퍼 20.48 ms)이 이후 모든 실시간 처리 예산의 기준이다.

## 통과 기준 (확정일 기록 없음 — 원문 "이 단계의 목표"를 사후에 옮김)
| 항목 | 기준 | 측정 조건 |
|---|---|---|
| 동시 샘플링 | ADC1 ~ 3 삼중 동시 변환, TIM2 트리거 | 설정 확인 |
| 끊김 없는 수집 | 핑퐁 버퍼, `dropCnt` 0 | 통계 계산만 하는 부하 |
| 마이크 출력 | 각 채널 바이어스·잡음 바닥 정상 | CubeMonitor 통계 그래프 |
