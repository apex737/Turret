## v5 — 장치 경로 녹음을 학습에 (2026-10-19 설계, 2026-10-23 결과): 미달
- 바꾼 것 (계획): 학습 FPV(DVIDS·Freesound 9분) + 학습 비드론(FSD50K 200클립 16분) + 시험 비드론(ESC-50 150클립 12.5분)을 무작위로 섞어 A·B 두 파일(각 23분) → 노트북 스피커 → 보드 STREAM → `embed_v5.py` 정렬·라벨 → `train_v5.py` v3m · v5p · v5 비교

| 설계 | 이유 |
|---|---|
| 양성·음성을 한 파일에 섞음 | 따로 녹음하면 그날 방 잡음이 "드론 표시"가 된다 |
| 음성도 같은 스피커로 (v5) | 양성만 넣으면 "스피커 음색 = 드론"을 배운다. v5p는 대조군 |
| ESC-50은 시험 전용 | 장치 경로 오탐/시간을 처음으로 잰다 |
| 원음과 같은 묶음 이름 | 원본·장치 녹음이 교차검증에서 갈라지면 문턱이 낙관적이 된다 |

- 가짜 녹음 검증: 시작 오차 5 ms 이하, 시계 차이 오차 7 ppm 이하. 녹음 절차는 [docs/run.md](../../docs/run.md).
- 판정 기준 (녹음 전 확정, 2026-10-20):

| 항목 | 성공 | 근거 |
|---|---|---|
| 장치 경로 FPV 창 재현율 (v5) | > 0.12, 목표 ≥ 0.25 | 0.12 = 장치 경로를 거치지 않은 사본만 넣어도 나오는 값 (가짜 녹음 대조) |
| 장치 경로 FPV 20 s 구간 검출 | 기준선 6/18보다 많음 | 사건 단위 판정 |
| 공개 원음 오탐 | ≤ 1회/시간 유지 | 채택 운용점의 조건 |
| 장치 경로 창 오탐률 (ESC-50) | ≤ 1% | 클립 1개 = 약 7회/시간이라 오탐/시간은 거친 참고 |
| v5p 대 v5 | v5p의 장치 오탐이 v5보다 높으면 지름길 확인 | 대조군 |

- 녹음 (2026-10-22 ~ 23): devpath_A·B 각 25분, 유실·CRC·클리핑 0. 재생 시작 17.39 s / 6.52 s, 시계 차이 +45 / +54 ppm, 4분 구간별 정렬이 직선으로 이어짐. 녹음 레벨이 speaker_10min보다 약 6 dB 작다 (재생 −20 → 녹음 약 −39 dBFS, speaker_10min은 −19.6 → −32.4). 드론·비드론이 똑같이 작아 크기 지름길은 없고, 학습 쪽 SNR이 시험보다 낮다.
- 결과 ([v5_report](../../reports/step8/v5_report.md)):

| 설정 | 공개 FPV 창 재현율 | 공개 사건 | 공개 오탐/시간 | 장치 FPV 창 재현율 | 장치 FPV 20 s 구간 | 장치 창 오탐률 (ESC) | 장치 오탐/시간 (클립) |
|---|---|---|---|---|---|---|---|
| v3m | 0.22 | 17/21 | 0.77 | 0.05 | 6/18 | 6.8% | 82 (12/150) |
| v5p | 0.32 | 16/21 | 1.15 | 0.14 | 12/18 | 9.6% | 130 (19/150) |
| v5 | 0.24 | 15/21 | 0.77 | 0.07 | 7/18 | 4.2% | 34 (5/150) |

- 판정 (위 기준): 장치 FPV 창 재현율 0.07 ≤ 0.12 → **미달**. 20 s 구간 7/18 > 6/18 → 겨우 충족. 공개 오탐 0.77 → 충족. 장치 창 오탐률 4.2% > 1% → **미달**. v5p 장치 오탐 9.6% > v5 4.2% → 지름길 확인.
- 해석: 장치 경로 비드론을 같이 넣으면(v5) 장치 오탐은 6.8 → 4.2%로 줄지만 FPV는 거의 그대로다. FPV만 넣으면(v5p) FPV가 오르는 만큼 오탐도 오른다 → 장치 음색을 드론으로 배운다. **새로 드러난 것: 채택 운용점(v3m)이 장치 경로에서는 창 오탐 6.8%, 82회/시간이다** (지금까지는 공개 원음 오탐만 쟀다). 오탐 범주가 재채기·홀짝임·숨소리·캔 따기·노크 같은 작고 짧은 소리다 → 창마다 −30 dBFS로 키울 때 남는 보드 자체 잡음(프레임 동기 빗이 FPV 기본음 대역 340 ~ 490 Hz에 남음, logs/Step5.md)을 드론으로 보는 것으로 추정. 미확인.
