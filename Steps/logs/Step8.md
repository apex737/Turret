## v4 (C1) — 분류기만 MLP + 운용점 분석 (2026-10-19): MLP 기각
- 바꾼 것: MLP(2048 → 256 → 1, 드롭아웃 0.5), 시드 2개. `diag_v4_curve.py`로 문턱별 곡선 ([v4_report](../../reports/step8/v4_report.md), [v4_curve](../../reports/step8/v4_curve.png))
- 결과: 같은 문턱(창 오탐 1%)에서 v2 + MLP는 FPV 0.43 → 0.56~0.57, 장치 경로 FPV 0.13 → 0.30, 오탐 8~11회/시간 그대로, Matrice 통과 AUC 0.45 → 0.23~0.28. 시드 흔들림 FPV ±0.1, 오탐 ±3회/시간.

| 데이터 · 분류기 | 오탐 ≤ 1/h: FPV 창 재현율 · 사건 검출 | ≤ 2/h | ≤ 5/h |
|---|---|---|---|
| v2 · 직선 | 0.07 · 71% | 0.15 · 71% | 0.31 · 81% |
| v2 · MLP | 0.11 · 62~71% | 0.25~0.29 · 71% | 0.46~0.51 · 81% |

| v3m · MLP | 0.08~0.19 · 57~76% | 0.18~0.23 · 76~81% | 0.35~0.43 · 81% |

- 해석: 목표 구간(오탐 ≤ 1~2회/시간)에서는 v3m · 직선이 가장 낫다. MLP는 5회/시간 이상 허용할 때만 낫다.
- 채택 (D8-5): v3m · 직선, 문턱 창 오탐 0.5% → 오탐 0.77회/시간 (2클립), 사건 17/21 = 81% (놓친 4건 모두 Matrice 300 통과), FPV 3/3 (확실한 양성 구간 시작부터 4~6 s 뒤, 머리 위 근처), 확정 지연 정의상 최소 1.5 s, 장치 경로 FPV 창 재현율 0.05. 0.5%는 1·0.5·0.2·0.1% 네 값을 시험 결과와 함께 보고 고른 것이라 약간 낙관적.

## v5 — 장치 경로 녹음을 학습에 (2026-10-19 설계): 녹음 대기
- 바꾼 것 (계획): 학습 FPV(DVIDS·Freesound 9분) + 학습 비드론(FSD50K 200클립 16분) + 시험 비드론(ESC-50 150클립 12.5분)을 무작위로 섞어 A·B 두 파일(각 23분) → 노트북 스피커 → 보드 STREAM → `embed_v5.py` 정렬·라벨 → `train_v5.py` v3m · v5p · v5 비교

| 설계 | 이유 |
|---|---|
| 양성·음성을 한 파일에 섞음 | 따로 녹음하면 그날 방 잡음이 "드론 표시"가 된다 |
| 음성도 같은 스피커로 (v5) | 양성만 넣으면 "스피커 음색 = 드론"을 배운다. v5p는 대조군 |
| ESC-50은 시험 전용 | 장치 경로 오탐/시간을 처음으로 잰다 |
| 원음과 같은 묶음 이름 | 원본·장치 녹음이 교차검증에서 갈라지면 문턱이 낙관적이 된다 |

- 가짜 녹음 검증: 시작 오차 5 ms 이하, 시계 차이 오차 7 ppm 이하. 녹음 절차는 [docs/run.md](../../docs/run.md).
