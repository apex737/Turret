## 질문과 답
**Q.** 기본 알고리즘을 연결한 상태에서 수음과 처리 마감을 지키는가?

**A. 아직 모른다.** STM32 쪽 방향 결과 패킷(약 0.25 s마다)까지만 됐고, PC 분류를 붙인 30분 운용은 미측정이다.

## 최종 목표와의 연결
- G4: 이 Step의 기준이 곧 G4다. Step9B(혼합음)보다 먼저 한다.
- I1·I4: 통신 단절·CRC 오류·클리핑을 주입해 감지·관측 무효화·정상 창 확보 후 복귀를 확인한다.
- I3: 동일 저장 입력의 PC 기준과 통합 결과를 비교한다.

## 통과 기준 (Roadmap 4.5.2 v0.4, 2026-10-15 확정)
| 항목 | 기준 | 측정 조건 |
|---|---|---|
| 유실 | ADC/DMA 유실·OVR 0, 처리 지연 누적 없음 | 전체 부하 30분 |
| CPU | ≤ 70% (초기 여유 목표). 평균만으로 마감 통과를 판정하지 않음 | 최대값 기록 |
| DMA 인계 | 원본 반버퍼를 다음 덮어쓰기 전 20.48 ms 이내 확보 | — |
| 분류 경로 | 100 ms 갱신 구성이면 관측 최악 시간 < 100 ms, 큐 비누적 | — |
| PC 대비 | 유효 방향 차이 ≤ 1°, 검출 사건 판정 일치, 출력 갱신 간격 이내 타이밍 차이 | 동일 저장 입력 |
| 고장 주입 | 통신 단절·CRC 오류·클리핑 → 감지·무효화·복귀 | 별도 시험 |
