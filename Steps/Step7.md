## 질문과 답
**Q.** 현재 3마이크(7 cm 정삼각형)에서 필요한 방위 오차와 유효율을 만족하는가?

**A. 예 (단일 음원, 채널 지연 보정 조건).** 12방향 오차 중앙값 최대 2.7°, p95 최대 6.8°, 유효율 최소 93% (기준 ≤ 5° / ≤ 10° / ≥ 80%). MCU 이식도 PC와 지연 차이 0.0001 샘플, CPU 최대 48%.

## 최종 목표와의 연결
- G1: 이 Step의 기준이 곧 G1이다.
- I3: MCU 이식(`doa.c`)은 PC 기준과 같은 녹음으로 비교해 통과했다.

## 통과 기준 (Roadmap 4.5.2 v0.4, 2026-10-15 확정. MCU 이식 기준은 2026-10-18 시험 전 확정)
| 항목 | 기준 | 측정 조건 |
|---|---|---|
| 방위 오차 | 유효 출력 중앙값 ≤ 5°, p95 ≤ 10° | 12방향 × 1회, 왼쪽 스피커 1 m, 같은 높이 |
| 유효율 | ≥ 80% (평가 대상 = 배경 대비 SNR ≥ 6 dB 창) | 같음 |
| MCU = PC | 양쪽 유효 창 지연 차이 ≤ 0.02 샘플, 각도 차이 ≤ 0.2°, 판정 일치 ≥ 99%, `cpu_max_pct` < 80%, 유실 0 | `compare_mcu.py` |
